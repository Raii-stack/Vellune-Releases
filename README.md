# Vellune for Android

[Download Vellune](https://github.com/Raii-stack/Vellune-Releases/releases/latest) and read the release notes.

Choose the **arm64** APK for a 64-bit ARM phone or the **x86_64** APK for an Intel or AMD Android emulator.

If Android reports a signing conflict with an earlier test build, export your library in **Theme Studio → Export ZIP backup** before uninstalling. Install the public APK, then import the backup.
